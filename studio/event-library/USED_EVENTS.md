# USED EVENTS — the spent-events ledger

Every shipped video's main events, so the next build can check what the last
two videos already spent (WORKFLOW.md §1.4). **Seeded 2026-11-13 from the
written project records** (scene plans / progress files / ledgers) — best
effort from notes, not from re-watching the masters; rows are therefore
headline-level. From MV-15 onward, rows are appended at delivery from the
build's own plan (WORKFLOW.md §4).

Reading the seed: MV-11 through MV-14 were montage-first builds whose plans
already ran "one gag per shot" — the rows below name the *recurring and
signature* events, not all 57–70 shots. The honest pattern the seed shows:
the last four videos all spent their distinctness budget on CARRY + WORLD
changes (a glowing post-rendered object in every scene while eras/worlds
snap-cut) and one-gag-per-shot prop business — while the library families
Transformation, Scale, Gravity, Multiplication, Crowd, and Weather are
nearly untouched across all four. That is the repetition this ledger exists
to catch.
