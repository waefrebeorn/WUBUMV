# CPU ASR 2026 — index sources (search results, 2026-11-10 unless noted)
- faster-whisper 1.2.1 (31 Oct 2025, last commit Nov 2025 per AwesomeOSAI Sep 2026). CTranslate2, int8 CPU/GPU, word_timestamps, Silero VAD (VAD upgraded to Silero-VAD V6 in 1.2.1). Batched pipeline vad_filter defaults True, transcribe() defaults False. GOTCHA: plain pip install pulls PyAV 19, transcription fails TypeError metadata_errors; pin PyAV 17/18.1.0. Source: https://www.pyinns.com/python/llm-and-generative-ai/speech-to-text-python-faster-whisper-2026 and https://whipscribe.com/tools/faster-whisper
- Whisper weights unchanged since large-v3 (Nov 2023) and large-v3-turbo (Oct 2024, 809M, decoder 32->4 layers). Turbo int8 ~1.5GB, large-v3 int8 ~2.9GB (faster-whisper). CPU: large-v3 on i9 RTF ~2.5 (2.5x slower than realtime); turbo encoder identical so CPU gain is small — decoder pruning helps GPU mainly. One 4-core laptop test: whisper.cpp turbo q5_0 11s clip took 136s, faster-whisper same 127s recording in 31s (base.en). Treat CPU speed claims for turbo with scepticism; verify on own VM. Sources: https://runaihome.com/blog/whisper-large-v3-self-hosted-transcription-server-2026/ , https://www.logeshwaran.org/2026/10/run-whisper-locally.html
- Distil-Whisper distil-large-v3: 756M, English-only, ~6.3x faster than large-v3, WER within ~1pt. Source: https://www.promptquorum.com/power-local-llm/local-whisper-stt-comparison
- Parakeet TDT 0.6B v2 (May 2025, English-only, 6.05% WER, song-to-lyrics advertised by NVIDIA) and v3 (Aug 2025, 25 EU langs, 6.18%). TDT decoder predicts token durations -> native word timestamps, no autoregressive repetition loop in principle. Runs via NeMo (GPU), sherpa-onnx / onnx-asr (CPU ONNX), whisper.cpp parakeet-cli. Speech CPU: sherpa-onnx int8 RTF ~0.03 in one Oct 2026 harness (speech, not singing) — https://metavert.io/speech-recognition . v3 dropped whole sentences depending on chunking in same harness. Sources: https://developer.nvidia.com/blog/nvidia-speech-ai-models-deliver-industry-leading-accuracy-and-performance/ , https://arxiv.org/html/2509.14128v1
- Qwen3-ASR 1.7B/0.6B + ForcedAligner, 29 Jan 2026, Apache-2.0: https://huggingface.co/Qwen/Qwen3-ASR-1.7B-hf — Open ASR Leaderboard Oct 2026: 1.7B 5.40% avg WER, ahead of Whisper large-v3 7.16% (36th). Explicit singing/BGM support. 0.6B 2000x throughput at concurrency 128 (GPU/vLLM). No CPU benchmark found — GPU-oriented (Transformers/vLLM, FlashAttention); 0.6B CPU trial is an experiment, not a given.
- SenseVoice Small 234M, Paraformer 220M, FunASR: non-autoregressive, timestamps, SenseVoice claimed 17x realtime CPU, Paraformer 15x. FunASR-Nano 800M (SenseVoice encoder + Qwen3-0.6B) handles sung lyrics per sherpa-onnx docs, but large/slow on CPU. Languages: SenseVoice 5 (zh/yue/en/ja/ko), Paraformer mainly zh. No singing benchmark found. Source: https://www.funasr.com/en/models.html , https://awesomeosai.com/self-hosted/speech-to-text
- Moonshine: tiny 27M, no native word timestamps in ONNX engine; skip for this pipeline. Source search 2026-11-10.
- MMS / SeamlessM4T: multilingual, no singing-specific advantage found, heavy; not shortlisted.
- VocalParse arXiv 2605.04613 (May 2026): https://arxiv.org/html/2605.04613v1 — Qwen3-ASR-based LALM, joint lyrics+melody+word-note, lyric-conditioned mode, SOTA SVT. Research code https://github.com/pymaster17/VocalParse — not a CPU pipeline; watch only.
- Interspeech 2026 Greek ALT: fine-tuning Whisper large-v3 2-stage -> WER 27.2% vs zero-shot; scaling helps. https://www.isca-archive.org/interspeech_2026/frangiadaki26_interspeech.pdf
